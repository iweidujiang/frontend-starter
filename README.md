# Frontend Starter

《前端项目实战手册》系列文章配套代码仓库。

## 技术栈

| 工具 | 版本 | 用途 |
|------|------|------|
| Vue | 3.x | 框架 |
| Vite | 5.x | 构建工具 |
| TypeScript | 5.x | 类型系统 |
| Vue Router | 4.x | 路由 |
| Pinia | 2.x | 状态管理 |
| Axios | 1.x | HTTP 客户端 |
| Element Plus | 2.x | UI 组件库 |
| ESLint + Prettier | - | 代码规范 |
| Husky + lint-staged | - | Git 钩子 |

## 快速开始

```bash
# 安装依赖
pnpm install

# 本地开发
pnpm dev

# 代码检查
pnpm lint

# 格式化
pnpm format

# 构建生产包
pnpm build

# 预览构建产物
pnpm preview
```

## 项目结构

```text
src/
├── api/            # 接口请求封装
├── assets/         # 静态资源
├── components/     # 公共组件
├── composables/    # 组合式函数
├── router/         # 路由配置
├── stores/         # Pinia 状态管理
├── styles/         # 全局样式
├── utils/          # 工具函数
├── views/          # 页面视图
├── App.vue         # 根组件
└── main.ts         # 入口文件
```
